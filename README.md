# Zadania

Aplikacja do zadań dla zespołu (telefon + komputer): zadania z listą pozycji, zdjęcia, komentarze,
przypisywanie osób i odhaczanie produktów z magazynu (wydanie zapisuje się w arkuszu Magazyn QR).

- `index.html` — aplikacja (PWA, GitHub Pages)
- `Code.gs` — kopia skryptu Google Apps Script (arkusz „Zadania”); po zmianie wklej go w edytorze skryptu
  i zrób **Wdróż → Zarządzaj wdrożeniami → Edytuj → Nowa wersja**
- `sw.js` — przy każdej zmianie podnieś `CACHE` razem z `APP_VER` w `index.html`

Wygląd: 7 motywów kolorystycznych (jasny/ciemny) z tłami — zdjęcia z [Unsplash](https://unsplash.com) (licencja Unsplash, darmowe), ładowane bezpośrednio z images.unsplash.com.
